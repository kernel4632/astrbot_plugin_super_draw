astrbot生图插件
        astrbot指令
                生图
                        解析内容，直接将提示词和解析出的图片透传给生图函数，并立即响应回复任务内容。不触发LLM回复，防止生成两次
                生图取消
                        直接取消发送该指令的用户的最近一次任务
                生图积分
                        立即返回该用户的积分
                生图预设
                        添加
                                格式为“预设名:提示词内容”
                        删除
                        查看
                生图模型
                        无参数就列出模型列表，有数字参数就切换模型
                生图开关
                        反转开关
        astrbot工具
                super_draw
                super_draw_data
                super_draw_ban

                启用生图
                启用 LLM 工具
                生图黑名单
                调试模式
                API 供应商配置
                        可添加条目
                                OpenAI兼容接口
                                Gemini接口
                        插槽模版
                                供应商名称
                                接口类型
                                请求地址
                                API Keys
                                可用模型列表
                生图配置
                        当前生图模型
                        最大重试次数
                        生图超时时间
                        最大队列长度
                积分制
                        启用积分制
                        每次有效发言获得积分
                        发言加分冷却（秒）
                        每次生图消耗积分
                        400错误扣除积分
                        新用户初始积分
                        Bot 数据工具
                生图后评价
                        启用工具生图后评价
                        生图后评价模型
                        生图后评价模板
                        生图后评价最大字数
                预设配置
                        可添加条目
                        插槽模版
                                预设名称
                                提示词内容
